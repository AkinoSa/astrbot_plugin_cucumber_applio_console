Applio 现代架构与核心功能全景

本插件基于现代 Applio v2 引擎架构构建，专为高性能 RVC 变声与群聊多媒体娱乐量身打造：

现代 RVC 变声算法 (RMVPE)

采用业内顶级 RMVPE 音高检测与自适应特征检索，极少哑音、电音或破音，高度还原目标角色声线细节与唱腔情感。

高保真人声伴奏分离 (云端固定 1297 旗舰模型)

支持 BS-Roformer 与 UVR5 现代深度网络。云端 Kaggle 算力环境固定且强制搭载业内顶级 BS-Roformer 1297 (SDR 12.9755) 旗舰人声分离网络，人声提取极其纯净，伴奏保留完整立体声声场与动态打击感。

TTS 角色语音回复

群聊触发文字回复时，先经高拟真 EdgeTTS 生成语音，再由 Applio 极速转换为专属角色声线发送。

混合云算力无感调度

兼备「本地一体化」与「Kaggle 混合云」两种算力架构，长音频变声上云白嫖双卡 T4 GPU，离线时本地自动平滑兜底。

运行环境 全流程 100% 运行在本地主机 / 设备 翻唱交由云端双卡 GPU；TTS 在本地极速响应

配套 Docker 推理网关部署 (cucumber-applio-gateway)

本插件为纯调度与交互端，底层模型推理与人声分离由独立 Docker 容器 cucumber-applio-gateway 承担（支持普通家用无显卡 CPU 主机，作为 TTS 实时变声与云端离线兜底核心）：

  1. 在宿主机拉取网关仓库或直接通过预构建镜像 ghcr.io/akinosa/cucumber-applio-gateway:1.0.0 部署（docker compose pull && docker compose up -d）。
  2. 按目录准备模型资产：weights/（.pth 音色）、indices/（同名 .index，可选）、pymss_weights/（3_HP-Vocal-UVR.pth）、hubert_base/、rmvpe/。
  3. 在插件设置中填写 网关服务地址（如 http://127.0.0.1:3333/，末尾需带 /）以及与网关 RVC_WORK_DIR 完全一致的 网关工作目录。

音频效果与 Reverb 空间混响调教

• 为什么需要混响：AI 变声出的人声处于完全无声场反射的「纯干音」状态，听感容易生硬突兀。Reverb 混响为人声叠加物理空间立体残响，润色毛刺感，使人声自然融入伴奏。
• 一键预设推荐：在左侧「音频效果」选项卡中提供 4 个一键预设：
  • 录音棚 (通透温润·推荐)：流行人声首选，湿音 0.08，人声咬字极清澈且通透贴耳。
  • 音乐大厅 (空间宽广)：适合慢歌与高音抒情大歌，声场宽宏空灵。
  • 现场演出 (Live 氛围)：模拟演唱会 Live 现场残响。
  • 关闭混响 (原生干音)：输出无混响干音原声。

统一任务注册表与并发排队规则

• 防抢占与 FIFO 队列：为保护本地网关与云端 GPU 不被并发压垮，同一时间严格只运行 1 首翻唱任务。新任务会自动进入队列排队，并实时播报排队序号（如“排队第 1 位”）。
• 防重复提交：同一用户、同会话下提交相同的歌曲请求，在时间窗口内系统会拦截并提示“正在排队处理中，无需重复点歌”。
• 任务接力不超时：排队任务会在前序任务完成的瞬间秒级接力，云端看门狗在排队期间持续保持活跃，全部任务清空后才开始计算 10 分钟关机倒计时。

Cloudflare Tunnel 永久固定公网域名配置指南

为了让处于美区机房的 Kaggle 与你的本地宿主机建立毫秒级安全的双向互通，推荐使用 Cloudflare Tunnel 进行公网穿透：

方案 A：Cloudflare + 国内其他域名商 (如阿里云 / 腾讯云 / 华为云 / 西部数码) ★最常用推荐

如果你的域名是在阿里云、腾讯云等国内平台购买的，可以通过将 DNS 权威服务器托管到 Cloudflare，享受永久免费的泛域名 Wildcard SSL 与全球边缘加速：

  1. 将域名添加至 Cloudflare：登录 Cloudflare 控制台，点击 Add a Site，输入你的主域名（例如 yourdomain.com），计划选择 Free (免费版)。
  2. 修改域名 DNS 服务器 (Nameservers)：Cloudflare 会给出两个专属 NS 地址（如 carlos.ns.cloudflare.com 和 paloma.ns.cloudflare.com）。前往阿里云/腾讯云的域名管理控制台，找到「DNS 修改 / 自定义 DNS」，把原有的默认 DNS 服务器改为 Cloudflare 给出的这两个地址。保存后等待 5~15 分钟生效。
  3. 创建 Cloudflare Tunnel：在 Cloudflare 左侧导航栏进入 Zero Trust → Networks → Tunnels，点击 Create a Tunnel，类型选择 Cloudflared，命名为 kaggle-rvc，复制页面上显示的 TUNNEL_TOKEN 密钥。
  4. 添加 Public Hostname (公共主机名)：在创建好的隧道配置中，切换到 Public Hostname 标签页，点击 Add a public hostname：
    • Subdomain (子域名)：填 rvc（即生成 rvc.yourdomain.com）
    • Domain (主域名)：选择你刚绑定的主域名
    • Type：选 HTTP
    • URL：填 localhost:7865
    点击 Save hostname 保存。Cloudflare Edge 会自动秒级为你签发全球受信任的 Let's Encrypt SSL 安全证书！
  5. 填入 Notebook 与插件：
    • 在 Kaggle 笔记本 kaggle_applio_runner.ipynb 的第一格中填入你的 TUNNEL_TOKEN；
    • 在本插件的「设置 → Kaggle 云端设置」中将端点填为 https://rvc.yourdomain.com。以后每次启动隧道永久固定，终身无需再改地址！

方案 B：纯 Cloudflare 域名 (全托管)

若你的域名直接在 Cloudflare Registrar 注册或已全权托管在 Cloudflare，无需进行步骤 2 的 NS 修改，直接从步骤 3 开始创建 Tunnel 并绑定 Public Hostname 即可，一分钟内配通！

方案 C：零域名快速临时体验 (TryCloudflare)

如果你暂时没有个人独立域名，也可以在 Kaggle 笔记本中直接运行。Cloudflare 会分配一个临时的 https://xxxx.trycloudflare.com 免费域名。将该地址复制到插件设置中同样可以使用（缺点是每次完全关机后重新开机，临时域名会变化）。

可选指南 云端音色模型挂载指南（放与不放的区别及操作步骤）
▾

1. 在云端放与不放模型的区别

放置模型 (Kaggle Dataset 挂载·强烈推荐)
  • 极速出歌，零网络开销：模型权重与特征索引永久固化在云端存储，开机即秒级加载，无需每次翻唱跨公网从本地上传。
  • 节省家庭上传带宽：避免每次冷启动都往美区机房上传数十兆的大文件，特别适合主力声线。
  • 实例重启不丢失：即便实例每天关机休眠，下次开机模型依旧挂载在云端。
不放置模型 (按需本地上传 / 缺省拦截)
  • 关闭上传时：若云端未放置且关闭了本地上传开关，系统将自动拦截未就绪的声模并友好报错，避免盲目消耗 GPU 额度。

2. 怎么把模型放到云端（Kaggle 私有数据集挂载步骤）

  1. 在 Kaggle 创建私有数据集：登录 Kaggle 官网，点击左侧菜单 Datasets → + New Dataset。为数据集命名（如 my-rvc-models，注意保持默认的 Private 私有状态以保护资产安全）。
  2. 上传本地音色资产：将本地目标音色的 .pth 权重文件及配套的 .index 特征文件（支持多个音色一次性拖入），拖入上传区域，点击右下角 Create 完成创建。
  3. 在 Notebook 关联挂载数据集：打开用于运行 Applio 的 Kaggle 笔记本（编辑状态），在右侧面板的 Input 区域点击 + Add Input；在弹出窗口切换至 Your Datasets 标签页，找到刚才创建的数据集，点击右侧加号完成关联。
  4. 全自动发现免配置：挂载后，数据集将出现在 /kaggle/input/数据集名称 目录下。启动实例时，服务会自动扫描所有子目录并就绪音色，无需您在终端执行任何复杂拷贝命令！
